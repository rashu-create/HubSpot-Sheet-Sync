# Archived one-shot scripts

These scripts finished their job and are kept for reference only. They hardcode
column letters from the layout at the time they ran, so **do not re-run them**
against the current sheet (e.g. `insert_qualified_column.py` would insert a second
column).

| Script | What it did |
|---|---|
| `insert_qualified_column.py` | Inserted the Qualified column at AI (2026-09-29) |
| `verify_qualified_column.py` | Checked that insert |
| `clear_columns.py` | Wiped stale cols AF/AH (2026-08-21) |
| `diagnose_owner_colD.py` | One-off debug of the Owner? column |
| `diagnose_graphify.py` | One-off lookup diagnostic |
| `discover_properties.py` | Produced `docs/property-map.txt` |
